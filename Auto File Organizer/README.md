# 📁 Auto File Organizer (Python)

## 🧠 Overview
This project is a simple Python automation script that organizes files inside a folder automatically.  
It sorts files into categories like Images, Videos, and Others based on file extensions.

---

## 🎯 Features
- Automatically scans a folder
- Detects file types by extension
- Creates folders automatically if they don’t exist
- Moves files into correct folders
- Handles basic errors safely

---

## ⚙️ How it works
1. Reads all files inside a target folder
2. Checks each file type (extension)
3. Matches file to a category
4. Moves file into the correct folder
5. Unmatched files go to "Others"
