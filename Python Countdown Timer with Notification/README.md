# ⏳ Python Countdown Timer with Notification

A simple Python countdown timer that displays time in **MM:SS format** and sends a desktop notification when the timer finishes.

## 🚀 Features

* Real-time countdown in terminal
* Clean MM:SS format display
* Desktop notification when time is up
* Easy to use and beginner-friendly

## 🛠️ Requirements

Make sure you have Python installed.

Install the required library:

```bash
pip install plyer
```

## ▶️ How to Run

```bash
python timer.py
```

Then enter the time in seconds:

```
Enter the time in seconds: 120
```

## 📸 Example Output

```
02:00
01:59
01:58
...
00:01
Fire in the hole!
```

## 🔔 Notification

After the countdown ends, you will receive a desktop notification:

* Title: Timer Finish!!
* Message: Great job
