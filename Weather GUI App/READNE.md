🌦️ Weather GUI App

A simple Python desktop app that shows current weather for any city using a graphical interface.

🚀 Features
Get weather by city name
Shows temperature, wind speed, and condition
Saves results to CSV file
Simple GUI using Tkinter
🛠️ Tech Stack
Python
Tkinter
Requests
Open-Meteo API
▶️ How to Run
pip install requests
python main.py
📊 Example Output
Berlin: 18°C, Wind 12 km/h, Clear sky ☀️
📁 Files
main.py → main app
Weather_data.csv → saved data
⚠️ Notes
City name must be correct
Internet connection required
