# 🌦️ Python Weather GUI App

A simple Python desktop application that fetches real-time weather data for a given city and displays it using a graphical interface.

---

## 🚀 Features
- Get current weather by city name  
- Displays temperature, wind speed, and weather condition  
- Saves weather data automatically to a CSV file  
- Simple and clean GUI using Tkinter  

---

## 🛠️ Requirements
Make sure you have Python installed.

Install required library:

pip install requests

---

## ▶️ How to Run

python main.py

Then enter a city name in the input box and click **Get Weather**.

---

## 📸 Example Output

Berlin: 18°C, Wind 12 km/h, Clear sky ☀️

Time | City | Temperature | Wind | Code | Status
